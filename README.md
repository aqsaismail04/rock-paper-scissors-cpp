## 📌 Overview

A fun **2-player console Rock Paper Scissors Game** built in C++.
Players choose their moves each round and the highest score wins!

---

## ⚙️ Features

| Feature | Description |
|---------|-------------|
| 🎮 2 Player | Both players enter their choice each round |
| 🔄 Multiple Rounds | Choose how many rounds to play |
| 📊 Score Tracking | Tracks score of both players |
| 🏆 Winner Display | Shows final winner at the end |
| 📜 Game Rules | Rules displayed before game starts |

## 🎮 How to Play

- Enter number of rounds
- Player 1 enters choice: `1` Rock, `2` Paper, `3` Scissors
- Player 2 enters choice: `1` Rock, `2` Paper, `3` Scissors
- Winner of each round gets a point
- Highest score at end wins!

---

## 🏆 Winning Rules

| Choice | Beats |
|--------|-------|
| 🪨 Rock | Scissors |
| ✂️ Scissors | Paper |
| 📄 Paper | Rock |

## ▶️ How to Run

### 🖥️ Visual Studio
1. Create new **Empty Project** → C++
2. Add `main.cpp` to project
3. Press **Ctrl + F5** to Run

### 💻 VS Code
```bash
g++ main.cpp -o rps
./rps
```

### 🖱️ Dev C++
1. Open `main.cpp`
2. Press **F11** to Compile & Run
